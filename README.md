# dsh-metaphysics · 命理排盘

Chinese metaphysics for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): BaZi (Four Pillars), Zi Wei Dou Shu, LiuYao, MeiHua YiShu, Da Liu Ren and Tarot.

给 DeepSeek Harness 用的命理插件：**四柱八字、紫微斗数、六爻纳甲、梅花易数、大六壬、塔罗牌**，同时提供 Agent 工具与 Web 面板。

> 传统命理与占卜属文化娱乐用途，不构成医疗、投资、法律或生死判断的依据。

## 插件市场备注

**命理排盘 · 八字 / 紫微 / 六爻 / 梅花 / 六壬 / 塔罗** —— 一个插件把六套体系装进 Harness：对话里说一句就排盘，侧栏还有可视化面板。

- **八字**：42 颗神煞（分吉凶七类，天干星双查年干与日干、三合星双查年支与日支，悬停看查法）、日主旺衰量化并给出依据、格局与用神（月令取格 + 化气/专旺/从格 + 十神组合，每条附判定依据）、大运流年按喜忌五行与十神打分（大吉/吉/平/忌/大忌，可看逐项理由）
- **紫微**：十四主星与 49 星曜、四层十二神、生年四化与宫干自化、34 条格局（标吉/忌倾向与依据）、大限一览、流年四化落宫；本命/大限/流年三视图一键切换，命宫红框、三方四正浅底标出
- **六爻**：摇卦或手动爻值、纳甲、六亲、六神、世应；本卦/变卦并列、真爻线渲染（阳爻整条、阴爻断开、动爻描红）
- **梅花**：时间/数字起卦、体用生克分档、互变错综四卦齐出，本卦上下卦分块标体用
- **大六壬**：天地盘 4×4 方盘（天盘大字、地盘小字、天将右下）、四课、九宗门三传、格局（贼克/元首/重审/伏吟/返吟/八专等）
- **塔罗**：78 张全牌、1/3/5 张牌阵，逐牌牌位义 + 整体解读，体系与逆位口径写明
- 全部本地计算，不收集数据；结果供文化娱乐参考，不作医疗、投资、法律或生死判断

## 功能

### 四柱八字（bazi）
- 四柱、藏干、十神、纳音、空亡（**逐柱**）
- **十二长生**：地势（日干对各支）、自坐（各柱干对本支）
- **神煞（42 星，7 类）**：贵人（天乙、太极、天德、月德、月德合、福星、天官、国印、天厨、天医）、文星（文昌、德秀）、婚姻（桃花、红鸾、天喜、孤辰、寡宿、金舆）、性情（华盖、羊刃、飞刃、魁罡、童子煞、六秀日、日德、日贵）、事业（禄神、将星、驿马）、凶煞（劫煞、灾煞、亡神、空亡、十恶大败、阴差阳错、四废日、流霞、天罗、地网）、格局（天赦日、金神、三奇贵人）。天干类双查年干与日干，三合类双查年支与日支；每颗星附查法依据，界面悬停可见
- **日主旺衰**：月令权重 + 通根 + 天干帮扶，量化分档，并给出依据（季节权重、通根地支、帮扶/耗泄明细）
- **格局与用神**：月令取格（建禄/阳刃/月劫/十神格）＋特格（化气、专旺、从格）＋十神组合（官印、杀印、食伤生财、财官、伤官配印、伤官见官、羊刃驾杀），每条附判定依据；用神取扶抑为主 + 简化调候提示，并列出喜忌十神
- **行运吉凶**：大运、流年按喜忌五行与十神加权评分，分大吉/吉/平/忌/大忌五档，悬停可看逐项理由
- **干支关系**：五合、相冲、相克；六合、三合半合、三会半会拱会、冲、害、破、刑
- 大运、流年（含与原局地支的关系）、真太阳时（按出生地经度修正）

### 紫微斗数（ziwei）
- 农历（定朔 + 冬至置闰）、命宫、身宫、五行局
- 紫微/天府、十四主星、六吉六煞、禄存天马、**49 颗星曜**
- 四层十二神：长生、博士、将前、岁前
- 生年四化、宫干自化、大限、小限、流年（命宫、三方四正、流禄流羊流陀）、斗君
- **格局识别（34 条，附判定依据与吉/忌倾向）**：紫府同宫、紫府朝垣、君臣庆会、极向离明、七杀朝斗、英星入庙、石中隐玉、巨日同宫、日月夹命、日月对照、左右/昌曲/魁钺夹命、三奇嘉会、双禄朝垣、机月同梁、府相朝垣、禄马交驰、月朗天门、日出扶桑、武贪同行、火贪铃贪；忌格：火铃夹命、羊陀夹命、羊陀夹忌、铃昌陀武、命里逢空、马头带箭、天罗地网、刑囚夹印、泛水桃花
- **大限一览**：十二限排序列出宫位、年龄区间、宫干四化落宫、三方主星；**流年四化**：逐年给出四化星落宫与命宫三方主星
- 昌曲专论：与丑未的关系、是否入命三方、吸收面清杂

### 六爻（liuyao）
- 摇卦或手动爻值、本卦/变卦、纳甲、六亲、六神、世应
- 面板：本卦与变卦并列对照，真爻线渲染（阳整、阴断、动描红），世应与动爻一目了然
- 只需起卦时刻（取日辰定六神、月建定旺衰），与出生时间无关

### 梅花易数（meihua）
- 时间起卦（年月日时数）或数字起卦（两数取余、可手动指定动爻）
- 本卦 / 互卦 / 变卦 / 错卦 / 综卦五盘齐出；本卦上下卦分块并标「体」「用」
- 体用生克按五行判吉凶：用生体大吉、比和吉、体克用吉、体生用耗、用克体凶

### 大六壬（daliuren）
- 月将加时起天地盘（4×4 方盘：天盘大字、地盘小字、天将右下）
- 四课（干上/支上递推，标注生克与天将）、九宗门发三传（贼克·元首·重审·比用·涉害·遥克·昴星·别责·八专·伏吟·返吟）
- 昼夜贵人（以天盘临方定顺逆）、旬空标注、格局名与断语

### 塔罗（tarot）
- 78 张全牌、正逆位、1/3/5 张牌阵
- 每张牌给编号、牌阶级、核心义与牌阵位义；解读 6–8 段（逐牌、大阿卡纳占比、五行分布、宫廷牌、正逆位比例、关键牌、建议）
- 明确标注体系：RWS 编号、黄金黎明元素归属、逆位取「弱化/未顺/内化」而非凶断

## 安装

### 从 npm

```bash
dsh plugin install dsh-metaphysics
```

或在 Harness 的「插件」面板里搜索 `dsh-metaphysics`。

### 从本地目录

```bash
dsh plugin install /path/to/dsh-metaphysics
```

### 从 tgz

```bash
dsh plugin install ./dsh-metaphysics-0.6.0.tgz
```

## 使用

### 对话里

直接说：

- 「排个八字：1990-05-12 14:30，女，河北石家庄」
- 「排紫微盘：1996-01-19 07:40，男，新疆喀什」
- 「帮我起一卦，问这个项目能不能成」
- 「梅花易数，报两个数 17 和 29」
- 「起个六壬课，问这周谈判顺利吗」
- 「抽三张塔罗，问这份工作要不要接」

模型会调用 `metaphysics_chart` 工具，参数 `system` 取 `bazi` / `ziwei` / `liuyao` / `meihua` / `daliuren` / `tarot`。
注意：八字与紫微要**出生时间**；六爻、梅花、六壬只要**起卦时刻**（通常就是当下），与出生时间无关。

### 面板

重启后侧栏出现**太极图标**，点开是排盘面板，支持以上四类。

## 精度与口径

- **节气**：Meeus 低精度太阳黄经，与公开历书相差 −3 ~ −8 分钟；出生时刻距「节」不足 15 分钟时会提示复核
- **农历**：定朔（Meeus 第 49 章，误差约 1 分钟）+ 冬至所在月为十一月 + 无中气置闰
- **真太阳时**：经度差 + 均时差；内置 34 个省会 + 200 个地级市坐标（±0.2°），地址更细时可开「联网精确到区县」（Nominatim）
- **紫微四化**：中州派常用表（庚干作太阳禄、武曲权、太阴科、天同忌）
- **日主旺衰**：量化算法，非唯一流派

## 数据与隐私

- 全部计算在本地完成
- 唯一可能的网络请求：开启「联网精确到区县」时的 OpenStreetMap Nominatim 查询；失败即回退内置坐标表
- 不收集、不上传任何数据
