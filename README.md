Chinese metaphysics for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): BaZi (Four Pillars), Zi Wei Dou Shu, LiuYao, MeiHua YiShu, Da Liu Ren and Tarot.

> 传统命理与占卜属文化娱乐用途，不构成医疗、投资、法律或生死判断的依据。

### 解析与详解（interpret）
每个体系的排盘结果下方都会跟一个「解析与详解」模块，帮你把盘面翻译成能看懂、能照着做的事。对话工具里加 `withInterpret: true` 即可一并返回。

- **结构化输出**：`{ moduleType, system, title, lead, dimensions[], sections[], disclaimer }`；`moduleType` 为 `natal`（命盘）/ `divination`（卦象）/ `card`（牌阵），`dimensions` 固定五个维度
- **五个维度**：整体运势、工作与职业选择、事业发展、爱情与感情、健康状况——每项给「解读 + 行动建议」
- **依据可核对**：每个维度都附一行「依据」，列出这条结论引用的事实——命盘类（八字/紫微）给日主旺衰、月令、喜忌、大运流年、宫位主星与煞星；卦象类（六爻/梅花/六壬）给本卦互卦变卦、世应、动爻、三传四课与神将；塔罗给牌阵、主轴、正逆位与元素分布。面板与文本两条输出路径都会显示
- **推导可复核**：八字/紫微另有「看盘顺序」「时间窗」「交叉校验」「未纳入」四段——先看什么后看什么、未来几步大运与近五年流年、喜忌分量与运年是否同向、以及这套算法**没有**计算什么；六爻/六壬对应给「看卦/看课顺序」与「未纳入」。这些都从盘面数据推出，不新增断语
- **卦象**（六爻/梅花/大六壬）额外给：卦名与卦辞大意、爻辞与动爻、体用关系、互卦与变卦、落到生活里
- **塔罗**额外给：整盘连贯解读（把几张牌串成一条线，避免各张互相矛盾）与牌面结构（大阿卡纳占比、元素分布、正逆位）
- **文案口径**：第二人称、温和、只给倾向与建议，不作绝对判断；底部保留理性参考的免责提示
- **解读区可折叠**：内容较长（五维度 + 体系模块），点标题栏或箭头即可展开/收起；宽屏默认展开、窄屏默认收起，手动切过之后按你的选择来

### 所问之事与询问方向（六爻 / 梅花 / 大六壬 / 塔罗）

问事的体系要先说清问什么，解读才有落点：

- **所问之事**：必填，支持多行，占位示例「用一句话描述所问之事，例如：今年是否适合换工作？」；不填就起卦会给提示，不会给一份没有落点的解读
- **询问方向**：下拉选择——综合（默认）、财运、事业、感情、健康、学业、出行。选项表 `DIRECTIONS` 由 `engine/interpret.js` 导出，界面与解析层共用一份，不两处维护
- **联动方式**：`interpret(result, { question, direction })`。所选方向对应的维度会被提到最前并标注「最贴近你的问题」，正文点明你所问的事，引语也会回显；解读开头固定一行「问题：xxx ｜ 询问方向：xxx」供你确认
- **不重摇卦**：改问题或方向只重出解读，卦象本身不动
- 命盘类（八字 / 紫微）不问事，不显示这两项，也不会出现回显行

## 使用

### 对话里

直接说：

- 「排个八字：1990-05-12 14:30，女，河北石家庄」
- 「排紫微盘：1996-01-19 07:40，男，新疆喀什」
- 「帮我起一卦，问这个项目能不能成」
- 「梅花易数，报两个数 17 和 29」
- 「起个六壬课，问这周谈判顺利吗」
- 「抽三张塔罗，问这份工作要不要接」

模型会调用 `metaphysics_chart` 工具，参数 `system` 取 `bazi` / `ziwei` / `liuyao` / `meihua` / `daliuren` / `tarot`。
注意：八字与紫微要**出生时间**；六爻、梅花、六壬只要**起卦时刻**（通常就是当下），与出生时间无关。

### 面板

重启后侧栏出现**太极图标**，点开是排盘面板：紫微 / 八字 / 六爻 / 梅花 / 六壬 / 奇门 / 合盘 / 塔罗八个 tab。奇门 tab 里「换局规则」可选拆补、超神接气、置闰；盘面下方用键值表列出局数、值符值使、空亡驿马等事实，与解读区的结论分开。

> 独立页（`命理排盘.html`）同样是这八个 tab：合盘要填双方出生信息、可选八字/紫微两种合盘；奇门用「换局规则」单选组（拆补/超神接气/置闰）与「询问方向」定用神。两份文件是**各自生成**的：重新构建后要单独同步你在用的那份拷贝（见「开发」里的 `--out`）。

### 深色与导出

- **深色主题**：跟随系统（`prefers-color-scheme`），盘面与页面同时切换，只换一套 CSS 变量，元素规则一行不改
- **打印永远是浅色**：深色主题下直接打印会得到一整页耗墨的深底 PDF，所以深色规则用 `@media screen` 限定
- **存为 PDF / 打印**：结果下方有按钮，走浏览器原生打印（不引第三方库）；A4 纵向、隐藏输入区与按钮、盘面与解读不被撕页、四化色块保留颜色。折叠着的「解析与详解」在打印时会自动展开，不会只印出一个标题栏

## 精度与口径

- **节气**：VSOP87B 截断级数（105 项）+ 岁差 + 章动 + 光行差；与日本国立天文台《暦要項》对拍，2024/2025 共 48 个节气最大偏差 **0.6 分钟**；出生时刻距「节」不足 20 分钟时会提示复核。**1929-01-01 之前按北京地方平时（UTC+7.7611）**推算，之后按东八区——与农历共用同一套换算，避免 14 分钟错位
- **农历**：定朔（Meeus 第 49 章，误差约 1 分钟）+ 冬至所在月为十一月 + 无中气置闰
- **真太阳时**：经度差 + 均时差；内置 34 个省会 + 200 个地级市坐标（±0.2°），地址更细时可开「联网精确到区县」（Nominatim）。**单盘与合盘用的是同一套修正**（合盘双方各按自己出生地算）。只按经度修正，**未含历史时区与夏令时**：海外出生请先把当地钟表时间换算成东八区标准时再输入；没给经度时摘要首行会出 ⚠
- **晚子时**：八字/大六壬默认 23:00 后换日，奇门默认归当日；`lateZi` 与 `lateZiHourMode` 是同一个开关的两个名字。各体系摘要都会写明本次采用的口径，不改默认值、不偷偷改盘
- **可复现**：塔罗/六爻给 `seed` 即得同一次抽牌/摇卦；紫微流月流日流时、塔罗的抽牌时刻、八字的流年基准年都可传 `asOf` 钉死
- **紫微四化**：中州派常用表（庚干作太阳禄、武曲权、太阴科、天同忌）
- **日主旺衰**：量化算法，非唯一流派
- **入参**：日期按月份天数与闰年校验（`1990-02-30` 直接报错，不滚到下个月）；八字/紫微/合盘的性别必填（性别决定大运大限顺逆，不做默认）；六爻爻值必须正好 6 个，留空才随机摇卦。非法入参带错误码返回（`E_INPUT` / `E_LINES` / `E_COUNT` / `E_ASOF` / `E_PARTNER`），不静默改成另一个盘
- **对拍**：历法对 NAOJ 历要项与 ICU 抽样的农历；流派规则对典籍通例——六爻八宫卦序与世应（京房）、六壬日干寄宫与中气换将（《大六壬指南》）、紫微纳音定五行局与紫微天府相照（《紫微斗数全书》）；另有《增删卜易》9 条与《卜筮正宗》**128 条**原文卦例（93 条本卦→变卦 + 35 条静卦）。期望值在 `test/fixtures/classics.json`，出处见其 `meta.sources`，卦例原始数据与排除理由在 `tools/data-boshizhengzong.mjs`。卦例只取原文能稳定读出的字段：卦名、卦宫、缺爻（伏神）、动爻**个数**（与原文 x/○ 标记数核对过）、有日期的旬空；**动爻在哪一爻**不录——卦象表在 PDF/DOCX 里串行，硬解析等于造数据

## 数据与隐私

- 全部计算在本地完成
- **默认不联网**：地址只查内置坐标表（最细到地级市，足够真太阳时）。只有把 `geocode` 设为 `online`（面板上勾「联网精确到区县」）才会把出生地原文发给 OpenStreetMap Nominatim，用于精确到区县/路名；失败即回退内置表，同一地址 6 小时内不重复请求
- 不收集、不上传任何其他数据


也可以直接调脚本：`node tools/build-client.mjs`、`node tools/build-html.mjs`、`node tools/test-all.mjs`、`node tools/check-assertions.mjs`、`node tools/verify-tests-can-fail.mjs`、`node tools/check-html-sinks.mjs`、`node tools/check-patterns.mjs`、`node tools/release.mjs`。

**测试的四道闸 + 一道稳定性扫射**：

1. `test/_harness.mjs`——任何一条 `ok()` 失败都让进程非零退出（此前 9 个文件只打印不失败，全量"全绿"没有意义）
2. `test/assertion-baseline.json`——每个文件的 PASS 条数低于基线即失败，防止"删断言让测试变绿"
3. `tools/verify-tests-can-fail.mjs`——故意写错一条断言，必须真的变红，防止第 1 条被改回去
4. `tools/check-html-sinks.mjs`——`innerHTML` 里拼接的量必须经过白名单转义函数，否则 CI 直接红
5. `tools/check-patterns.mjs`——engine 不得引用浏览器/Node API 与 `console`，不得用 `var`/`debugger`，`new Date()` 与 `Math.random` 只允许出现在白名单文件
6. `test/fuzz.test.mjs`——固定种子的随机生日扫射八个体系，覆盖边界日期、参数矩阵与"同参数必得同结果"

`client.js` 是构建产物，不要手改；改动记录见 [CHANGELOG.md](CHANGELOG.md)。

### 样式命名约定

面板的 CSS 是以 `<style>` 注入到宿主页面的，**没有 shadow DOM 隔离**，所以每个类名都带命名空间前缀，避免和宿主页面的同名元素互相染色：

| 前缀 | 归属 |
|---|---|
| `pp-` | 紫微盘骨架（宫格、宫位选中、三方四正、身宫） |
| `bz-` | 四柱八字表（干支大字、藏干、十神、五行旺衰） |
| `dt-` | 宫位详情面板 |
| `flow-` | 流月 / 流日 / 流时 |
| `ct-` / `ft-` | 盘心 / 盘脚 |
| `mp-` | 各模块根容器：`mp-it`（解析）、`mp-dl`（六壬）、`mp-hy`（六爻）、`mp-mh`（梅花）、`mp-tt`（塔罗）、`mp-hex`（爻线）、`mp-trib`（体用） |
| `hb-` / `tritag-` | 卦盒 / 体用标签 |
| `dl-` / `ss-` / `ssx-` / `ssg-` | 六壬盘块 / 神煞族 |
| `ask-` | 所问之事回显 |

两条硬规矩：

- **不用泛词做类名**（`.body`、`.big`、`.s`、`.p`、`.on`、`.it` 这类）。名字越泛，越容易在同一个文件里被两处语义共用——本项目已经栽过两次：`.pp-body` 同时是「整块视图容器」和「身宫格」，一次导致身宫整格消失，另一次的 `::after` 残骸在页面左上角飘出一个孤立的「身」方块。
- **模块根类名必须带前缀**。裸用的 `.it` / `.dl` / `.hy` 一旦注入全局，宿主页面的同名元素会被一起改写。

*2026-10 做过一轮全量整改：199 个类名按语义分组补齐前缀（约 540 处替换），计算逻辑一行未动，20 组断言与全量视口扫描全绿。*
