# dsh-metaphysics · 命理排盘

Chinese metaphysics for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): BaZi (Four Pillars), Zi Wei Dou Shu, LiuYao, MeiHua YiShu, Da Liu Ren and Tarot.

给 DeepSeek Harness 用的命理插件：**四柱八字、紫微斗数、六爻纳甲、梅花易数、大六壬、塔罗牌**，同时提供 Agent 工具与 Web 面板。

> 传统命理与占卜属文化娱乐用途，不构成医疗、投资、法律或生死判断的依据。

- **日主旺衰**：月令权重 + 通根 + 天干帮扶，量化分档，并给出依据（季节权重、通根地支、帮扶/耗泄明细）
- **格局与用神**：月令取格（建禄/阳刃/月劫/十神格）＋特格（化气、专旺、从格）＋十神组合（官印、杀印、食伤生财、财官、伤官配印、伤官见官、羊刃驾杀），每条附判定依据；用神取扶抑为主 + 简化调候提示，并列出喜忌十神

- **干支关系**：五合、相冲、相克；六合、三合半合、三会半会拱会、冲、害、破、刑

### 解析与详解（interpret）
每个体系的排盘结果下方都会跟一个「解析与详解」模块，帮你把盘面翻译成能看懂、能照着做的事。对话工具里加 `withInterpret: true` 即可一并返回。

- **结构化输出**：`{ moduleType, system, title, lead, dimensions[], sections[], disclaimer }`；`moduleType` 为 `natal`（命盘）/ `divination`（卦象）/ `card`（牌阵），`dimensions` 固定五个维度
- **五个维度**：整体运势、工作与职业选择、事业发展、爱情与感情、健康状况——每项给「解读 + 行动建议」
- **卦象**（六爻/梅花/大六壬）额外给：卦名与卦辞大意、爻辞与动爻、体用关系、互卦与变卦、落到生活里
- **塔罗**额外给：整盘连贯解读（把几张牌串成一条线，避免各张互相矛盾）与牌面结构（大阿卡纳占比、元素分布、正逆位）
- **文案口径**：第二人称、温和、只给倾向与建议，不作绝对判断；底部保留理性参考的免责提示
- **解读区可折叠**：内容较长（五维度 + 体系模块），点标题栏或箭头即可展开/收起；宽屏默认展开、窄屏默认收起，手动切过之后按你的选择来

### 所问之事与询问方向（六爻 / 梅花 / 大六壬 / 塔罗）

问事的体系要先说清问什么，解读才有落点：

- **所问之事**：必填，支持多行，占位示例「用一句话描述所问之事，例如：今年是否适合换工作？」；不填就起卦会给提示，不会给一份没有落点的解读
- **询问方向**：下拉选择——综合（默认）、财运、事业、感情、健康、学业、出行。选项表 `DIRECTIONS` 由 `engine/interpret.js` 导出，界面与解析层共用一份，不两处维护
- **联动方式**：`interpret(result, { question, direction })`。所选方向对应的维度会被提到最前并标注「最贴近你的问题」，正文点明你所问的事，引语也会回显；解读开头固定一行「问题：xxx ｜ 询问方向：xxx」供你确认
- **不重摇卦**：改问题或方向只重出解读，卦象本身不动
- 命盘类（八字 / 紫微）不问事，不显示这两项，也不会出现回显行

## 使用

### 对话里

直接说：

- 「排个八字：1990-05-12 14:30，女，河北石家庄」
- 「排紫微盘：1996-01-19 07:40，男，新疆喀什」
- 「帮我起一卦，问这个项目能不能成」
- 「梅花易数，报两个数 17 和 29」
- 「起个六壬课，问这周谈判顺利吗」
- 「抽三张塔罗，问这份工作要不要接」

模型会调用 `metaphysics_chart` 工具，参数 `system` 取 `bazi` / `ziwei` / `liuyao` / `meihua` / `daliuren` / `tarot`。
注意：八字与紫微要**出生时间**；六爻、梅花、六壬只要**起卦时刻**（通常就是当下），与出生时间无关。

### 面板

重启后侧栏出现**太极图标**，点开是排盘面板，支持以上四类。

### 深色与导出

- **深色主题**：跟随系统（`prefers-color-scheme`），盘面与页面同时切换，只换一套 CSS 变量，元素规则一行不改
- **打印永远是浅色**：深色主题下直接打印会得到一整页耗墨的深底 PDF，所以深色规则用 `@media screen` 限定
- **存为 PDF / 打印**：结果下方有按钮，走浏览器原生打印（不引第三方库）；A4 纵向、隐藏输入区与按钮、盘面与解读不被撕页、四化色块保留颜色。折叠着的「解析与详解」在打印时会自动展开，不会只印出一个标题栏

## 精度与口径

- **节气**：Meeus 低精度太阳黄经，与公开历书相差 −3 ~ −8 分钟；出生时刻距「节」不足 15 分钟时会提示复核
- **农历**：定朔（Meeus 第 49 章，误差约 1 分钟）+ 冬至所在月为十一月 + 无中气置闰
- **真太阳时**：经度差 + 均时差；内置 34 个省会 + 200 个地级市坐标（±0.2°），地址更细时可开「联网精确到区县」（Nominatim）。只按经度修正，**未含历史时区与夏令时**：海外出生请先把当地钟表时间换算成东八区标准时再输入
- **紫微四化**：中州派常用表（庚干作太阳禄、武曲权、太阴科、天同忌）
- **日主旺衰**：量化算法，非唯一流派

### 样式命名约定

面板的 CSS 是以 `<style>` 注入到宿主页面的，**没有 shadow DOM 隔离**，所以每个类名都带命名空间前缀，避免和宿主页面的同名元素互相染色：

| 前缀 | 归属 |
|---|---|
| `pp-` | 紫微盘骨架（宫格、宫位选中、三方四正、身宫） |
| `bz-` | 四柱八字表（干支大字、藏干、十神、五行旺衰） |
| `dt-` | 宫位详情面板 |
| `flow-` | 流月 / 流日 / 流时 |
| `ct-` / `ft-` | 盘心 / 盘脚 |
| `mp-` | 各模块根容器：`mp-it`（解析）、`mp-dl`（六壬）、`mp-hy`（六爻）、`mp-mh`（梅花）、`mp-tt`（塔罗）、`mp-hex`（爻线）、`mp-trib`（体用） |
| `hb-` / `tritag-` | 卦盒 / 体用标签 |
| `dl-` / `ss-` / `ssx-` / `ssg-` | 六壬盘块 / 神煞族 |
| `ask-` | 所问之事回显 |

两条硬规矩：

- **不用泛词做类名**（`.body`、`.big`、`.s`、`.p`、`.on`、`.it` 这类）。名字越泛，越容易在同一个文件里被两处语义共用——本项目已经栽过两次：`.pp-body` 同时是「整块视图容器」和「身宫格」，一次导致身宫整格消失，另一次的 `::after` 残骸在页面左上角飘出一个孤立的「身」方块。
- **模块根类名必须带前缀**。裸用的 `.it` / `.dl` / `.hy` 一旦注入全局，宿主页面的同名元素会被一起改写。

*2026-10 做过一轮全量整改：199 个类名按语义分组补齐前缀（约 540 处替换），计算逻辑一行未动，20 组断言与全量视口扫描全绿。*
