## 2026-10-31 · 第一份（邮件 + GitHub issue #1）

- **环境**：dsh V0.2.1-rc.5 + dsh-metaphysics 0.55.0，面板排盘，真太阳时与晚子时换日均开启。
- **处理状态**：三条都已改并过七道闸，随 **0.56.0** 提交（`64b5c17`）、推送并发版（npm、tag `v0.56.0`、GitHub release）；回信已发至反馈者邮箱，并在 issue #1 留了同内容的公开版。

### 1. 输入区错位：「性别」比其他输入框低，「晚子时换日」偏移 —— 属实，已修

- **原因**（三处叠加）：
  1. 面板 CSS 没写 `box-sizing`。Chrome 下 `<select>` 默认 border-box、`<input>` 默认 content-box，同样 36px 时 input 实高 50px，按底对齐后性别下拉顶边低 14px。独立页有全局 `*{box-sizing:border-box}`，所以独立页不错位、面板错位。
  2. 「晚子时换日」被误套了 `mp-field mp-checks`，继承 `.mp-checks` 的 13px 上边距，在居中对齐的勾选行里下沉约一半：顶边低 6px、中线低 7px。
  3. 降列用的是视口 `@media`。侧栏宽度不等于窗口宽度，面板拖到约 600px 而窗口仍是 1200px 时照排四列，输入框被压到 117.5px。
- **改动**（`src/app.js`）：
  - `.mp-input` / `.mp-textarea` 补 `box-sizing:border-box`。
  - 「晚子时换日」改成与「真太阳时」「联网精确到区县」同构的普通勾选，并补 title 说明。
  - `.mp-wrap` 设 `container-type:inline-size`，按面板宽度在 860px / 480px 收成两列 / 一列；「八字 × 紫微 交叉验证」独占一行。
- **验证**：
  - 无头 Chrome 以面板实际 CSS 在 600 / 940px 两档实测：同排输入框顶边差 0，三项勾选中线一致，600px 收成两列（每列 249px）。
  - `test/panel-form-align.test.mjs` 11 条。
- **边界**：没有在 Harness 宿主里实机截图，宿主若另注入样式需再看一次。

### 2. 旺衰与喜忌：面板判「偏强 3.2」、喜火金水木、忌土；用户认为应喜火土、忌水木、金中性偏忌 —— 属实，已修

- **盘型**：亥月戊土，年支子、时支丑、日坐寅，天干透丙、己、癸。
- **原因**：旧算法逐支数藏干根气，不看地支会合。
  - 亥子丑三会水：丑中己土这条根已被水局带走，旧算法仍按足根计。
  - 寅亥合木：寅中戊土这条根被合绊，旧算法仍按足根计。
  - 天干己土在地支没有有效根，属虚透，旧算法仍按实帮计。
  - 三处叠加，把日主从偏弱抬到偏强，喜忌随之整体颠倒。
- **改动**（`engine/bazi.js` `branchRootFactors()`）：
  - **三会 / 三合成局**：局中各支的藏干根气按局的五行折算。与日主同五行不折；为日主之印折到 6 成；其余三会折到 1 成、三合折到 2 成。
  - **六合**：只折局外那一支。同类不折，为印折到 8 成，其余折到 5 成。
  - **半合 / 半会**：不折。
  - **虚透**：帮身的天干（比劫 / 印）折后根气不足 0.3 的，帮扶按半计。
  - **依据**：「合会折根」「虚透」两行同时写进依据与推导链。
- **现结果**（同型盘）：
  - 旺衰：偏弱 1.4。
  - 喜忌：喜火（印）、土（比劫）；忌金（食伤）、水（财）、木（官杀）。
  - 调候：寒湿取丙火，与扶抑同向。
- **关于「金中性偏忌」**：金在这类盘里分值约 0.3，是五行里最弱的一行，作用是食伤泄身。方向上与「中性偏忌」一致，但引擎的喜忌只有喜、忌两档、没有中性档，所以只能落在「忌」。
- **关于木**：扶抑把木（官杀）列为忌；《穷通宝鉴》十月戊土首取甲、次取丙，古法并不把木一律当忌。两者在盘面并列，不合并。
- **验证**：
  - `test/bazi-strength-structure.test.mjs` 32 条，覆盖：同型盘偏弱且喜火土；三会 / 三合 / 六合各一型；局内支不重复折；同类局与印局；无会合的盘不受影响；推导链两行；五档分布不塌缩。
  - 1990–2002 共 416 盘，五档分布（偏弱 / 中和 / 身弱 / 偏强 / 身强）由 52/82/56/114/112 变为 68/87/69/96/96，偏强与身强各降约 15%。
- **边界**：折算比例与 0.3 门槛是本仓取值，不是古籍定数，尚无第三方对拍集；方法说明仍写「属简化算法，非唯一流派」。

### 3. 紫微身主：「子午安身铃火宿」，子年有的盘显示铃星、有的显示火星，以哪个为准 —— 口径分歧，已并列两派

- **原因**：两种取法都有人用，旧版只按诀文逐字取一派（子铃星），没有说明另一派。
  - **通行表**（iztro 与多数排盘软件）：子、午年身主都是火星。
  - **安身主诀**「子午安身铃火宿」逐字配对：子年铃星、午年火星。
  - 午年两派相同；其余十支两派一致。
- **改动**（`engine/ziwei.js`）：
  - 新增流派开关 `shenzhuSchool`：`common`（默认，子午皆火星）/ `verse`（子铃午火）。
  - 子午年盘面带 `bodyMasterNote`，注明另一派；面板 `＊` 悬停可见。
  - 工具 schema、口径对照（紫微 11 → 12 组）同步。
- **默认值变化**：子年身主由铃星改为火星。想按诀文逐字取，传 `shenzhuSchool: 'verse'`。
- **出处**：此诀在维基文库本《紫微斗数全书》卷一、卷三未见；卷二未能访问、尚未核对。所以只标「安身主诀」，不标作《全书》原文。登记见 `docs/参考资料与对拍来源.md` §4。
- **验证**：
  - `test/ziwei-shenzhu.test.mjs` 29 条。
  - `test/caliber-diff.test.mjs` 补子年身主能检出、午年无差异。
  - `test/ziwei-schools.test.mjs` 开关数 9 → 10。
