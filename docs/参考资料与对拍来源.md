# 参考资料与对拍来源

> 外部页面、库与典籍只作口径参考与对拍。每条记清：地址、访问日期、采用了什么、怎么验证、哪些没采用。

## 1. ziwei.pub / 紫微派（八字页）

- **地址**：https://ziwei.pub/bazi
- **访问日期**：2026-10-31
- **采用的口径**
  - **命宫**：27 减生月与生时支，取模后加二；**身宫**：11 加生月与生时支，取模后加二；结果并入六十甲子（Tyme 1.5.4 口径）。
  - **胎元**：月干进一位、月支进三位；**胎息**：日干五合、日支六合。
- **采用的信息层次**（只借顺序，不抄文案）
  1. 基本信息
  2. 四柱（十神 / 五行 / 藏干 / 星运 / 自坐 / 旬空 / 纳音 / 神煞）
  3. 五行分布
  4. 命宫 / 身宫
  5. 胎元 / 胎息
  6. 起运与交运
  7. 大运流年
  8. 神煞
  9. AI 分析
  本插件把第 1–8 层用作 `READING_ORDERS` 的排序（末层换成「古籍依据」），第 9 层落在 `askPrompt` 的回答骨架（结论 → 骨架 → 判断 → 记忆点 → 边界），不把页面的 AI 文案搬进摘要。
- **验证**：用 `tyme4ts@1.5.4` 对 1950–2020 共 **704 组日期**逐组复算命宫 / 身宫 / 胎元，0 处不符；`test/bazi-palaces.test.mjs` 另锁 6 组样本与「胎息＝五合六合」「命宫支 + 身宫支序＝6」两条结构不变量。
- **未采用**：页面文案、视觉样式、页面内的 AI 生成内容；不把页面断语当作古籍原文，也不把页面的默认时区 / 晚子时口径直接搬成唯一口径。
- **边界**：页面按东八区与 Tyme 口径；本插件另有真太阳时、夏令时与晚子时开关，差异会在摘要首行与「晚子时」说明里写明。

## 3. 玄空 B5（替卦与年月日时紫白）

- **访问日期**：2026-10-31
- **替卦底本**：《沈氏玄空学》坤壬乙诀（子癸甲申贪狼、壬卯乙未坤巨门、乾亥辰巽巳戌武曲、酉辛丑艮丙破军、寅午庚丁右弼）。转引与阈值说明见 [网易「玄空风水兼向替卦星盘起法」](https://www.163.com/dy/article/EKQ8FU9L0528KRKP.html)、[阐微堂「替卦起星原理」](https://chanweitang.com/post/156.html)。
  - 采用：24 山全表；兼向超 4.5°（离山界 3° 以内）用替卦；山星/向星以替星入中，顺逆按替星本宫同元龙；同卦兼/出卦兼与「用替而未替」照实标出。
  - 未采用：蒋氏三元挨星、青囊奥语残缺诀、中州派十三山简诀；这些与本表并列会互相覆盖，暂不合并。
- **紫白底本**：[CSDN「年月日时紫白飞星法」](https://blog.csdn.net/weixin_34334554/article/details/112880704)、[豆瓣「紫白择日法的应用」](https://m.douban.com/note/728139479/)、[知乎「5 分钟推算紫白飞星」](https://zhuanlan.zhihu.com/p/571371295)。
  - 采用：年逐年退一位；月按年支三组起 8/5/2、逐月退一位；日按冬至–夏至三段起 1/7/4 与 9/3/6；时按日支三组子时起 1/7/4 与 9/3/6；阳遁顺飞、阴遁逆飞；月取节气月、日 23:00 换日。
  - 未采用/并列：有流派主张日星「一律顺飞」、月按农历月、时星阴遁仅星逆而宫仍顺；本插件取「阳顺阴逆」并在 note 写明异说，不把两派合并成一个结果。
- **验证**：`test/fengshui-tigua-zibai.test.mjs` 用 24 山表、4.5° 阈值、8 运子午改盘、5 运用替而未替，以及甲子日六段、冬夏×日支三组的子时起点作锚点；尚未与第三方完整玄空盘批量对拍，故只称「按底本复算」，不称「已对齐」。

## 4. 紫微身主（子/午年两派，`shenzhuSchool`）

- **访问日期**：2026-10-31
- **起因**：用户反馈（GitHub issue #1）问「子午安身铃火宿」为什么有的盘身主是铃星、有的是火星。
- **通行表（`common`，默认）**
  - [iztro 安星说明](https://iztro.com/learn/setup)：原文写「口诀在不同资料中可能有差异；本库将子年和午年的身主均设为火星」。
  - [「紫微斗数基础教程――从零学起」](http://m-zw.kvov.com/sswzx.php?id=5323333666655550513)：搜索摘要里写「其生年支在子則身主為火星……午，火星」。只看到摘要，没有抓全页。
- **逐字诀（`verse`）**：安身主诀「子午安身鈴火宿，丑未天相寅申梁，卯酉天同身主是，巳亥天機辰戌昌」，按字序配成子铃星、午火星。
  - 只在一条搜索摘要（福山堂「紫微教學·安星訣」）里见到，没有拿到稳定的页面地址。
  - 维基文库本《紫微斗數全書》卷一、卷三里没有这句（两卷正文已缓存在 `test/fixtures/citation-sources.json`，只搜到别的诗里的「羊铃火宿」）。卷二没有核：当晚维基文库连不上。
  - 所以盘面说明写的是「安身主诀」，不标作《全书》原文。
- **验证**：`test/ziwei-shenzhu.test.mjs` 29 条，核两派、子/午/其余十支、平铺与嵌套参数、非法值回默认、摘要、面板 `＊` 说明；`test/caliber-diff.test.mjs` 核「子年能检出差异、午年没有差异」。
- **未采用**：不判哪一派对；默认值取通行表，是因为它和 iztro 及多数排盘软件一致，便于用户拿别家的盘对照。

## 6. 新增参考时的约定

1. 先在本文件登记，再改代码；写清访问日期与采用范围。
2. 「采用」必须能指向一条测试或对拍证据；不能验证的只写「参考」，不写成「已对齐」。
3. 区分「口径」与「文案」：可以借层次与算法，不复制对方的解释文案与视觉。
4. 与既有口径冲突时，不静默覆盖；在摘要、CHANGELOG 与这里同时写明差异。
