> 外部页面、库与典籍只作口径参考与对拍。每条记清：地址、访问日期、采用了什么、怎么验证、哪些没采用。

## 1. ziwei.pub / 紫微派（八字页）

- **地址**：https://ziwei.pub/bazi
- **访问日期**：2026-10-31
- **采用的口径**
  - **命宫**：27 减生月与生时支，取模后加二；**身宫**：11 加生月与生时支，取模后加二；结果并入六十甲子（Tyme 1.5.4 口径）。
  - **胎元**：月干进一位、月支进三位；**胎息**：日干五合、日支六合。
- **采用的信息层次**（只借顺序，不抄文案）
  1. 基本信息
  2. 四柱（十神 / 五行 / 藏干 / 星运 / 自坐 / 旬空 / 纳音 / 神煞）
  3. 五行分布
  4. 命宫 / 身宫
  5. 胎元 / 胎息
  6. 起运与交运
  7. 大运流年
  8. 神煞
  9. AI 分析
  本插件把第 1–8 层用作 `READING_ORDERS` 的排序（末层换成「古籍依据」），第 9 层落在 `askPrompt` 的回答骨架（结论 → 骨架 → 判断 → 记忆点 → 边界），不把页面的 AI 文案搬进摘要。
- **验证**：用 `tyme4ts@1.5.4` 对 1950–2020 共 **704 组日期**逐组复算命宫 / 身宫 / 胎元，0 处不符；`test/bazi-palaces.test.mjs` 另锁 6 组样本与「胎息＝五合六合」「命宫支 + 身宫支序＝6」两条结构不变量。
- **未采用**：页面文案、视觉样式、页面内的 AI 生成内容；不把页面断语当作古籍原文，也不把页面的默认时区 / 晚子时口径直接搬成唯一口径。
- **边界**：页面按东八区与 Tyme 口径；本插件另有真太阳时、夏令时与晚子时开关，差异会在摘要首行与「晚子时」说明里写明。

## 3. 玄空 B5（替卦与年月日时紫白）

- **访问日期**：2026-10-31
- **替卦底本**：《沈氏玄空学》坤壬乙诀（子癸甲申贪狼、壬卯乙未坤巨门、乾亥辰巽巳戌武曲、酉辛丑艮丙破军、寅午庚丁右弼）。转引与阈值说明见 [网易「玄空风水兼向替卦星盘起法」](https://www.163.com/dy/article/EKQ8FU9L0528KRKP.html)、[阐微堂「替卦起星原理」](https://chanweitang.com/post/156.html)。
  - 采用：24 山全表；兼向超 4.5°（离山界 3° 以内）用替卦；山星/向星以替星入中，顺逆按替星本宫同元龙；同卦兼/出卦兼与「用替而未替」照实标出。
  - 未采用：蒋氏三元挨星、青囊奥语残缺诀、中州派十三山简诀；这些与本表并列会互相覆盖，暂不合并。
- **紫白底本**：[CSDN「年月日时紫白飞星法」](https://blog.csdn.net/weixin_34334554/article/details/112880704)、[豆瓣「紫白择日法的应用」](https://m.douban.com/note/728139479/)、[知乎「5 分钟推算紫白飞星」](https://zhuanlan.zhihu.com/p/571371295)。
  - 采用：年逐年退一位；月按年支三组起 8/5/2、逐月退一位；日按冬至–夏至三段起 1/7/4 与 9/3/6；时按日支三组子时起 1/7/4 与 9/3/6；阳遁顺飞、阴遁逆飞；月取节气月、日 23:00 换日。
  - 未采用/并列：有流派主张日星「一律顺飞」、月按农历月、时星阴遁仅星逆而宫仍顺；本插件取「阳顺阴逆」并在 note 写明异说，不把两派合并成一个结果。
- **验证**：`test/fengshui-tigua-zibai.test.mjs` 用 24 山表、4.5° 阈值、8 运子午改盘、5 运用替而未替，以及甲子日六段、冬夏×日支三组的子时起点作锚点；尚未与第三方完整玄空盘批量对拍，故只称「按底本复算」，不称「已对齐」。

## 4. 紫微身主（子/午年两派，`shenzhuSchool`）

- **访问日期**：2026-10-31
- **起因**：用户反馈（GitHub issue #1）问「子午安身铃火宿」为什么有的盘身主是铃星、有的是火星。
- **通行表（`common`，默认）**
  - [iztro 安星说明](https://iztro.com/learn/setup)：原文写「口诀在不同资料中可能有差异；本库将子年和午年的身主均设为火星」。
  - [「紫微斗数基础教程――从零学起」](http://m-zw.kvov.com/sswzx.php?id=5323333666655550513)：搜索摘要里写「其生年支在子則身主為火星……午，火星」。只看到摘要，没有抓全页。
- **逐字诀（`verse`）**：安身主诀「子午安身鈴火宿，丑未天相寅申梁，卯酉天同身主是，巳亥天機辰戌昌」，按字序配成子铃星、午火星。
  - 只在一条搜索摘要（福山堂「紫微教學·安星訣」）里见到，没有拿到稳定的页面地址。
  - 维基文库本《紫微斗數全書》卷一、卷三里没有这句（两卷正文已缓存在 `test/fixtures/citation-sources.json`，只搜到别的诗里的「羊铃火宿」）。卷二没有核：当晚维基文库连不上。
  - 所以盘面说明写的是「安身主诀」，不标作《全书》原文。
- **验证**：`test/ziwei-shenzhu.test.mjs` 29 条，核两派、子/午/其余十支、平铺与嵌套参数、非法值回默认、摘要、面板 `＊` 说明；`test/caliber-diff.test.mjs` 核「子年能检出差异、午年没有差异」。
- **未采用**：不判哪一派对；默认值取通行表，是因为它和 iztro 及多数排盘软件一致，便于用户拿别家的盘对照。

  - [ziweiscience 安星法](https://ziweiscience.com/index.php/2024-06-25/anxingfa/)（天官／天福／天才／天寿，4 颗）
  - [bilibili 安星诀专栏](https://m.bilibili.com/opus/1015667810277261321)（天厨／蜚廉／天德／年解，4 颗）

- **采用范围（三条硬口径）**：
  1. **两颗独立站点同表才收**。每颗星在不同站点上的十二月／十干表逐格比对，一致才进 `TABLE_*`；只有一处见到的星一律不收，不靠「看着像」补齐。
  2. **诀文照录，转抄例子与诀文相抵时以诀文为准**。天才的诀文三处一致（自命宫起子年，顺数至本生年支），但 360doc 那条转抄的例子写「命宫在午、戌年生人」却落「巳宫安天才」——从午起子顺数到戌应在辰宫（该盘夫妻宫正在辰），判为转抄笔误。实现按诀文走，这条判定写进模块 `note` 与知识卡 `note`。
  3. **同名异星不合并**：蜚廉（年支）≠ 博士十二神的飞廉；按年安的天德 ≠ 岁前十二神的天德；年解 ≠ 按月的解神（月解）。三组各归各位，面板上会出现两个「天德」，这是刻意的。
- **不收的两颗**：龙德、月德。它们与岁前十二神里的同名神煞起法一致、落宫一致，并入即在同一宫重复安同一颗星；`ZUOYAO_SKIPPED` 逐颗留了 20 字以上的理由，面板与复制提问都列这份清单。
- **为什么标「通行说」而不署《全书》**：维基文库本《紫微斗数全书》卷一是赋文与格局、卷二是安身命例（正文缓存在 `test/fixtures/citation-sources.json`），两卷都没有这套按年月与命身宫安杂曜的诀；`engine/citations.js` 因此记 `status: 'general'`，不带 `refs`，不伪造一条并不存在的原文。
- **验证**：`test/ziwei-zuoyao.test.mjs` 96 条——期望值全部由诀文里的地支字重导（不复制引擎表数字）、解神另用第二式（月建对冲）逐月独立互核、新库反查旧表（破碎／华盖／咸池三组三合位）、缺依据整颗跳过、两档盘面 49 vs 61、简盘星名是全表子集、三组同名异星并存不合并；面板用 `vm` 载入真 `panel-kit.js` + 真 `compute` 渲两档盘，逐条数 chip、入庙标、折叠诀文与未另立清单。变异验证：改表一格、改起宫偏移、撤参数守卫、撤模板里的杂曜块四处都能让对应用例转红。
- **未采用**：不判哪一家星曜更「灵」；默认 `minimal` 排 49 颗，为的是旧盘与已存命盘不变，全表要显式开。

## 6. 《钦定协纪辨方书》（择日神煞层，H5）

- **底本**：清乾隆六年内府刊朱墨套印本（四库全书本）。
- **工作副本**：殆知阁整理本 `xieji.txt`（834,869 字节 / 约 29 万字），卷十「宜忌」在 4576–5095 行（六等判词见 4853 行），卷十一「用事」在 5172–5384 行。该副本对「旨／会／瑴」等字有系统性替换（如「奉防」＝奉旨、「防议」＝会议），卷十「六等」判词首字「参」亦误作「防」，均按文义还字并在夹具注明；异体字（徳／隂／劵／惸／牀／啓／壊／隄／寃）在测试侧归一，不改底本。
- **刻本扫描件**：1694 个对开页 JPEG（1.27GB，无文本层），只用于核对卷次与版式，不做 OCR 取值。
- **采用范围**
  - 卷十一「用事」16 条事项的宜/忌清单，逐条照录；`test/fixtures/zeri-sources.json` 存原文串，测试用最长优先分词逐字还原，改一个字即红。
  - 卷四建除十二神「同位异名」、卷五/卷六「义例」月神起法、卷九「立成」逐日表，按节气月与日干支复算；天狗只按卷五按语作「申月戌日」。
  - 卷十「宜忌」六等判词逐字照录（上／上次／中／中次／下／下下，另立「平」）；德神制化按卷十各条按语分 `keJie`（德可解）／`buJie`（德犹忌）／`wuShe`（与德义不相属），并把「止忌……」的余忌按事项落回 `residualEntries`；月日条件（值守日／相日／王日／官日、孟仲季月值某建除、巳月值平日等）按原文实现。`test/fixtures/zeri-juan10.json` 存判词与 25 条制化关键词。
  - 无可靠起法的 10 条（土王用事后、血忌、伏社日、八风、气往亡、专日、伐日、四离、四绝、上朔）不计分，逐日 `shensha.unsupported` 列出。
- **未采用**
  - 卷十「宜忌等第表」的逐格矩阵：未数字化。吉／凶权重（建除、神煞各一颗）与六等比值阈值（3/2、1、2/3、1/2、下下合凶 12）是本仓校准，不是古籍常数；`meta.scope` / `disclaimer` 已明写，不拿它冒充完整黄历。
  - ctext.org 正文：按约定不抓；只作查询指针。
  - 刻本 OCR：竖排与分栏导致串列，已放弃；不拿 OCR 结果当原文。
- **验证**：`test/zeri-shensha.test.mjs` 20 条——卷十一 16 条原文逐字还原、卷十「六等」判词逐字还原、25 条德神制化关键词、阈值标注为本仓校准、计分名分档完整性、27 个事项映射、逐日定值（10-29 / 12-01 / 12-15 / 12-22）、灾煞遇德对开业可解而求医仍忌、月破德犹忌、四穷不能化解、月厌叠灾煞判下下、输出契约；既有 `tools.test.mjs` / `zeri-candidates.test.mjs` / `tools3.test.mjs` / `smoke-all.test.mjs` 保持绿。

## 8. 新增参考时的约定

1. 先在本文件登记，再改代码；写清访问日期与采用范围。
2. 「采用」必须能指向一条测试或对拍证据；不能验证的只写「参考」，不写成「已对齐」。
3. 区分「口径」与「文案」：可以借层次与算法，不复制对方的解释文案与视觉。
4. 与既有口径冲突时，不静默覆盖；在摘要、CHANGELOG 与这里同时写明差异。
