# 知识库：北派紫微斗数（讲义 02 沉淀）

来源与原文见 `docs/参考资料-北派紫微讲义02.md` 与同目录 OCR 全文（行号按 OCR 全文）。本文件只放**读法骨架与词义**，不进 `engine/`，不参与判定。

分三类，看标题就知道能不能落地：

- **可复算**：盘上有字段，能指回某一宫某一象。
- **词义**：只影响措辞，不影响结论。
- **师承口吻**：讲义原话有，但盘上无可复算字段，只留档不引用。

---

## 一、四化四组词义（词义，可进文案层）

OCR `:4565-4572`，四化象摘要第一条与第二条：

> 禄忌阴阳的对立面；禄因忌果。权科阴阳的互动面；权变科续。
> 禄权科忌＝春夏秋冬；禄权科忌＝缘起缘变缘续缘灭。

落成四个可用的说法：

| 化 | 词义 | 一句话 |
| --- | --- | --- |
| 禄 | 缘起 | 事情的来源、递梯子的那只手 |
| 权 | 缘变 | 过程中需要拿主意、会变盘的那一段 |
| 科 | 缘续 | 让它续下去的名声、体面、可交代 |
| 忌 | 缘灭 | 收不住、放不下的那一块 |

两两成组：禄忌是同一件事的因果两面（禄因忌果），权科是同一件事的变与续（权变科续）。讲义另有一句配属「禄忌一组，金水共乘航；权科一组，木火原一家」，属类象，不进代码。

现在的文案层已经用上这一组：`engine/ziwei-words.js` 的 `HUA_READ` 写的是态度（得/掌/名/执），`HUA_PAIR` 写的是配对（逢禄看忌、逢权看科）。四化词义不进判定，只解释「为什么它俩要一起看」。

## 二、三才（词义 + 可复算）

两套三才，别混：

**宫星化三才**（OCR `:4589`）：

> 星辰为天，宫位为空间／圈，地也。四化者，人也。化者为象，象者像也、显像事件也。

意思是断一件事要三样齐：星定性质，宫定场所，化定事件。盘上三样都有，缺一样就别硬断——这条可以直接当「不敢断」时的说法。

**宫位三才**（讲义第九讲，天地人分位）：

- 天位：子、午、卯、酉
- 地位：辰、戌、丑、未
- 人位：寅、申、巳、亥

讲义给的固定断语（四败天位主桃花、四库地位主劳碌）属**师承口吻**，不引用。可复算的用法只有一条：象落人位谈人（父命兄夫子奴），落物位谈物（财福田），落事位谈事（官迁疾）——这条 OCR `:4795` 附近讲义自己也补了「不可拘泥于（名也）」。

## 三、象的三重定语（可复算）

OCR `:4595-4600`，三条，按顺序套：

1. **依宫（职定义）**：禄在人位表人缘广，在物位表财禄现金，在事位表忙碌随性。同一颗星同一化，落宫不同就是不同的事。
2. **依星（辰定义）**：乙干天机化禄多主智慧机敏，辛干巨门化禄多主口才口福。星决定这件事长什么样。
3. **依干（性定义）**：庚干金，太阴化科主血光；癸干水，太阴化科主桃花。干决定走向的色调。

这三条是「同一个象为什么能读出不同的事」的合法理由。写文案时按 1→2→3 出词；盘上没有的（比如血光）不写。

## 四、双象六组（骨架，读法为延伸，非讲义断语）

讲义只列了六组名（OCR `:4601`）：禄权、禄科、权科、禄忌、权忌、科忌。每组的具体断语在「点睛合辑中」那批查表里，不可复算，不搬。

能用的只有**结构**：先分清哪一象是体（生年四化，先天）、哪一象是用（飞宫或自化，后天），再落宫职本义，最后才谈人事。按这个结构，六组各有一句读法骨架：

| 组 | 骨架 | 讲义的依据 |
| --- | --- | --- |
| 禄 + 权 | 来源顺，过程要自己拿主意，容易用力过猛 | 禄因、权变 |
| 禄 + 科 | 来得顺，还能靠体面续下去 | 禄起、科续 |
| 权 + 科 | 想主导，靠科把它收得漂亮 | 权变、科续 |
| 禄 + 忌 | 同一件事上既顺手又放不下，顺的时候别把余地用完 | 禄因忌果，一个太极 |
| 权 + 忌 | 想拿主意，偏偏那块是自己放不下的 | 权变、忌灭 |
| 科 + 忌 | 体面与执着拉扯，越要面子越收不住 | 科续、忌灭 |

禄+忌与权+科这两组已经在用（`HUA_PAIR`）。其余四组暂不进代码：单宫同落两象在盘上不算常见，硬塞会给多数盘加噪声。

双象的**五种类别**（OCR `:4602-4609`）可以当检查清单用：生年双象 / 生年逢自化 / 生年逢飞宫 / 飞宫逢自化 / 飞宫双象。盘上能算的是第一类与前两类混合，自化与飞化 `engine/ziwei.js` 各自有字段（`selfHua` / `flyChains`），别把两类混成一句。

## 五、阴阳是浮动定义（口径）

OCR 末页原话：

> 总结；阴阳两字是浮动性的定义！不要拘泥于一端，阴阳既是浮动，则其内涵完全看标点是如何定义的！

这条是本讲义用得最上的自我约束：它自己反对把「六内吉六外凶」「忌比禄力量大」写死，理由就是口径浮动。插件也是这个立场——`engine/ziwei.js:963` 与 `engine/ziwei-words.js:7` 的口径注释写「只描会照，不折吉凶」「不下断语」。两端口径并列留档，谁也别吃谁。

对外解释时可以直说：这类判词取决于流派怎么定义阴阳与内外，本盘只给结构，不给这类权重。
