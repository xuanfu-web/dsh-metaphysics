# 时辰未知：八字三柱模式（hourUnknown）方案

> 状态：**方案，未实施**。执行时间：**2026-11-02（明天）白天**。
> 硬约束：本改动触及八字引擎核心（时柱缺失会连带影响紫微命宫、大运起运、趋势 K 线、合盘，且下游 6000+ 条断言依赖时柱）。**不在凌晨前动核心**，避免把已通过的绿色门禁改红。

---

## 1. 要解决什么

用户常常只知道「几点左右」甚至完全不知道出生时辰。现在的行为是：没填时刻就默认一个时间（页面初始 `12:00`）继续排盘，结果里时柱、紫微命宫、起运日全都照常出现——**看起来像算过，实际是拿占位值算的**。

目标不是「把三柱算得更准」，而是**不骗人**：

- 时柱不排，并明确标注「时柱暂缺」；
- 任何依赖时柱的模块（紫微 / 趋势 / 合盘）不得静默使用假时柱：要么阻断，要么显式降级；
- 首屏必须有一句不可忽略的提示：**「时柱按正午暂算，涉及时柱的结论仅供参考」**。

## 2. 设计

### 2.1 引擎入参（`engine/bazi.js` 的 `buildBazi`）

- 新增 `hourUnknown: boolean`，默认 `false`；默认路径逐字节不变。
- `hourUnknown: true` 时：
  - `pillars.hour = null`、`hourZhi = null`，不生成时柱的十神 / 神煞 / 时空亡 / 时柱长生等一切派生字段（保持键存在但为 `null`，或整体缺失——二选一并写测试钉死）；
  - `notes` 增加「时柱暂缺：未提供出生时刻，时柱不参与任何判定」；
  - **不把任何钟点写进结果**：不得出现 `12:00` 或等价占位；内部只用语义标记 `provisionalHour: 'noon'`（正午），不落成时间字符串；
  - 大运：起运时刻依赖出生时刻，降级为「按日近似」，`dayun.jiao` 标 `precision: 'day'` 并写明「时柱暂缺，交运日仅供参考」。
- 摘要（`engine/index.js`）：**首行强制**写固定句「时柱按正午暂算，涉及时柱的结论仅供参考」，其后才是四柱/农历等常规行；句子里用「正午」，不写 `12:00`。

### 2.2 下游模块（`engine/ziwei.js` / `engine/trend.js` / `engine/hepan.js`）

原则：**禁止静默使用假时柱**。默认阻断，只有显式降级开关才继续，并全程带标记。

| 模块 | 为什么依赖时柱 | 默认行为 | 显式降级（可选） |
|---|---|---|---|
| 紫微 `ziwei` | 命宫由月+时定，命宫错则全盘错 | **阻断**：返回 `E_INPUT`（`code: 'HOUR_UNKNOWN'`）+ 一句话引导「请补出生时刻或改用三柱模式只看日柱信息」 | 不提供（紫微没有时柱就没有盘） |
| 趋势 `trend` | 起运/大运依赖时刻 | **降级**：按日级起运近似，顶部标「时柱暂缺，起运为按日估算」 | 已有 |
| 合盘 `hepan` | 双方夫妻宫/大运依赖时刻 | **阻断**（任一方 hourUnknown 即阻断） | 不提供（双方盘都不完整） |
| 八字交叉紫微 `cross` | 需要紫微盘 | 随紫微一起阻断 | 不提供 |

面板 / 独立页：

- 时间输入旁新增「时辰未知」勾选（默认不勾）；勾选后隐藏时刻输入，提交时传 `hourUnknown: true`；
- 结果首屏出现固定提示条（在结果卡最上方、折叠区之外）；
- 输入回显不得把 `12:00` 当成用户填的时间（不得出现「出生时刻 12:00」这类文本）。

### 2.3 三条验收断言（新增测试文件 `test/hour-unknown.test.mjs`）

1. **不得出现 12:00 占位**：`JSON.stringify(result)` 与 `renderText(result)` 全文不得匹配 `12:00`；面板/独立页提交后的输入回显也不得出现 `12:00`。
2. **不得当作已知**：`pillars.hour`、`hourZhi` 及依赖它的派生字段必须为空；摘要/解析中不得出现「时柱 X」「时支 X」「时柱十神」这类把时柱当已知的句子（用白名单断言，防止误报）。
3. **提示必须出现在首屏**：面板与独立页的结果 DOM 中，固定提示句出现在结果卡最前、且不在 `<details>` 内；摘要文本第一行即该提示。

补充：紫微/合盘在 `hourUnknown` 下必须返回 `HOUR_UNKNOWN` 错误（不是空结果、不是默认盘）；趋势必须带 `precision: 'day'` 标记。

## 4. 风险与回滚

| 风险 | 对策 |
|---|---|
| 下游 6000+ 断言里有用例默认传了时刻 | `hourUnknown` 默认 false，旧路径不变；只有显式传参才走新分支 |
| 紫微阻断被误当成 bug | 错误码 `HOUR_UNKNOWN` + 一句话引导，面板显示为「需要出生时刻」而非红色报错 |
| 「正午暂算」与「不得出现 12:00」冲突 | 文案统一用「正午」，内部只用 `provisionalHour: 'noon'`，任何地方不落 `12:00` 字样 |
| 大运/交运精度 | 降级为按日近似并在字段上标 `precision: 'day'`，不静默冒充日时级 |
