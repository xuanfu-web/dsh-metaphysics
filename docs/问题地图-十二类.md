# 问题地图：人们到底问命理什么

数据来源：`shunshi-ai/fate-bench`（335 题，2010–2026 全球算命師大賽）+ `DestinyLinker/MingLi-Bench`（160 题，2022–2025），按题记录合计 495 条，两批在 2022–2025 有重叠，比例以「题记录」计。

这份东西不用于给引擎打分。它的用处只有一个：**知道真实的人会问什么，以及老练的师傅从盘的哪一块回答**。

---

## 总量分布

| 类别 | 题记录数 | 占比 | 时间型占比 |
| --- | --: | --: | --: |
| 婚姻 | 123 | 25% | 30% |
| 事业 | 77 | 16% | 8% |
| 家庭（六亲） | 73 | 15% | 19% |
| 健康 | 52 | 11% | 25% |
| 财运 | 44 | 9% | 14% |
| 学业 | 37 | 7% | 3% |
| 性格 | 36 | 7% | 0% |
| 子女 | 24 | 5% | 67% |
| 运势 | 9 | 2% | 44% |
| 外貌 | 8 | 2% | 0% |
| 灾劫 | 6 | 1% | 50% |
| 官非 | 5 | 1% | 60% |

「时间型」＝题面直接问年份/时段。整体 21%，但答案落在年份上的题达 147 条（30%）——因为问法常常是「1999 己卯年發生何事」，年份在题面、事件在选项。

**结论一：命理咨询的真实需求是「什么时候」和「是什么」，不是「好不好」。** 吉凶判断只是附带，用户要的是可核对的事件锚点。

**结论二：婚姻占了四分之一，加上事业和家庭就是一半以上。** 这三块答不好，其余做得再深也没人用。

## 十二类问法地图

### 1. 婚姻（25%）

真实问法：
- 請問命主結婚之年在何年？
- 那年正式簽紙離婚？
- 推算命主何兩個流年為拍拖分手之年份？
- 請問以下那種是最貼近命主在 2001-2002 年之感情狀況？
- 請問此造於現在的婚姻關係？

盘上依据：
- **主看**：日支（夫妻宫）的合冲刑害；男命财星、女命官星的旺衰与位置
- **次看**：大运流年与日支的作用（冲则动、合则聚）；红鸾天喜；配偶星是否被比劫夺（男）或被食伤制（女）
- **判年**：流年地支与夫妻宫成合/冲之年

答案形态：年份 + 对象特征 + 关系走向。三样缺一，用户就觉得没答。

插件现状：**已有专用出口**（0.77.0 起，`engine/marriage.js`）——先定类型（晚成/有起伏/竞争/挑剔/远距离/平顺），再给 20–45 岁的动婚年份（未来优先、过去最多留两条），最后按配偶星五行与柱位给对象取象，五句以内。原先是 `geju.js` 有配偶星与宫位作用、`trend.js` 有流年打分，但没有「婚姻年」专用推法。
待补：婚姻年的权重仍只按「合冲夫妻宫 + 配偶星透干 + 红鸾天喜」四项线性相加，未做「先合后冲」「合处逢冲」的先后判定；二婚、异地婚这类结构信号还没单独分出来。

### 2. 事业（16%）

真实问法：
- 這個命職業類型？
- 命主 2012 年的事業情況如何？
- 此癸丑女命於 2016 丙申年發生何事，而令到命主現在沒有工作？
- 1999 己卯年工作情況？

盘上依据：
- **主看**：官杀（职位、上司、体制）、印（单位、靠山、资历）、食伤（技艺、创业、口才）
- **次看**：月柱（事业宫）与日主的关系；格局是官印相生还是伤官见官
- **判类型**：官印重 → 体制内；食伤生财 → 技术或经营；比劫重 → 合伙或体力
- **判起伏**：大运流年与月柱、官星的作用

答案形态：职业类型 + 起伏年份 + 宜忌（该不该换、该不该创）。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `career` 段）——先由「十神哪组最重 + 格局组合」定职业类型（体制内专业技术 / 做生意与技术变现 / 手艺加文凭 / 自由职业 / 合伙分成），再给 20–55 岁的升迁与转场年份（未来优先、同一条理由最多取两次），最后给一句顺的方向（用神五行 → 行业取向）。仍缺：职业类型落到具体岗位的细分，这一层要看本人会什么，盘上给不了。

### 3. 家庭／六亲（15%）

真实问法：
- 1976 丙辰年，唐山大地震中六親情況？
- 命主的母親於 2010 年時？
- 命主的弟弟妹妹同於那一年身亡？
- 以下那種是最貼近命主在 5-15 歲之父母情況？

盘上依据：
- **主看**：年月柱（祖上、父母）、月柱（兄弟）、日支（配偶）、时柱（子女）
- **次看**：父母星（印为母、财为父）、兄弟星（比劫）、六亲星在四柱的旺衰与刑冲
- **判年**：流年冲克对应宫位或六亲星之年

答案形态：谁 + 哪年 + 吉凶。三个都要，缺一个就是空话。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `kin` 段）——父看偏财、母看正印、兄弟看比劫，逐位给「厚 / 中 / 薄 / 不显」与一句人话；宫位那一段只作说明，不再逐柱铺术语。仍缺：祖上、六亲的具体事件与年份，这一层证据太弱，先不做。

### 4. 健康（11%）

真实问法：
- 命主何年因病（肺炎）而做手術？
- 請問命主在以下那一年，身體健康出了大問題（提示：為生死攸關的重病）？
- 1984 年命主有甚麼特別病患？
- 命主身患長期病症，究竟是何種病呢？

盘上依据：
- **主看**：五行偏枯（某一行过旺或全无）、忌神所主的脏腑、日支与月支受冲
- **次看**：七杀攻身、羊刃逢冲、岁运并临、三刑
- **判部位**：木肝胆、火心小肠、土脾胃、金肺大肠、水肾膀胱

答案形态：部位/病种 + 年份 + 轻重。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `health` 段）——按五行权重最高者指向「偏亢」、最低者指向「短板」，脏腑取木肝胆 / 火心小肠 / 土脾胃 / 金肺大肠 / 水肾膀胱，再给两三个「身体信号容易显」的年份。措辞固定为「留意」，并明写「不诊断、不建议用药、不替代就医」。仍缺：作息与体质的个性化建议——那需要医学知识，不该由排盘软件给。

### 5. 财运（9%）

真实问法：
- 命主 2009 己丑發生何事？
- 推算此命在 2009 己丑年事業成就，在香港平均一個月收入大約何階層命格？
- 命主一生中，擁有最多財富，人生之頂點，是哪一年？
- 總結命主的一生，最佳的形容字句？

盘上依据：
- **主看**：财星旺衰与位置、身财两停与否、比劫是否夺财、食伤是否生财
- **次看**：财库开合、正财偏财的得法（薪水 vs 经营 vs 偏门）
- **判顶点**：大运走财而身能任财的那十年，其间的流年

答案形态：量级（阶层，不是具体数字）+ 得法 + 破财年份。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `wealth` 段）——量级五档（富 / 小康以上 / 小康 / 过手财 / 守成为主 / 偏薄），依据财星权重、是否在喜用、有无食伤生财、比劫是否分财四条；财库开闭沿 `caikuOf`；比劫分账的年份**单独成句**，不混进财路窗口。仍缺：量级到数字的映射——这个换算没有任何可靠依据，不做。

### 6. 学业（7%）

真实问法：
- 請問此造的學歷程度？
- 此命在何年畢業，而投身社會工作？
- 這命學歷高低如何？
- 以下那個答案最接近命主中學時期的狀況？

盘上依据：
- **主看**：印星（文凭、考试运）、食伤（聪明、领悟）、官印相生与否
- **次看**：月柱（少年运）、大运走印之年
- **判层次**：印旺得用 → 高学历；食伤旺无印 → 聪明但读不下去；印被财坏 → 中途辍学

答案形态：学历层次 + 转折年份。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `study` 段）——四档（学历这条路顺 / 读书与做事打架 / 靠才华不靠文凭 / 学历一般自学为主），依据印星权重、是否在喜用、食伤与财的相对强度；顺年按印官透干加权，区间 12–30 岁。仍缺：具体学校与分数，不预测。

### 7. 性格（7%）

真实问法：
- 命主的性格特質？
- 此命性格如何？
- 命主個性如何？
- 命主的性格外表怎样？

盘上依据：
- **主看**：日主五行 + 旺衰；主导十神（比劫/食伤/财/官/印哪一类最多）
- **次看**：月令格局、阴阳比例、有无七杀羊刃

答案形态：3–5 个特征 + 一句总括。**不能超过五条，多了没人看。**

插件现状：`interpret-plain.js` 已有类似输出，是十二类里最成熟的一块。

### 8. 子女（5%）

真实问法：
- 請問命子女數目？
- 現在為止，有幾個小孩？
- 於命主虛齡 35 至 44 甲戌大運期間，其子女運？
- 此命於那年結婚，同年兒子出生？

盘上依据：
- **主看**：时柱（子女宫）；男命官杀为子女、女命食伤为子女
- **次看**：子女星的旺衰与个数、时柱受冲与否
- **判年**：流年与子女星、时柱成合之年

答案形态：数量 + 性别倾向 + 年份段。

插件现状：**已有专用出口**（0.77.0 起，`engine/facets.js` 的 `children` 段）——男命取官杀、女命取食伤为子女星，按权重给「偏旺 / 适中 / 偏薄 / 不显」，再看时柱状态与是否受冲。**不推个数、不推性别**，并在输出里写明原因。

### 9. 运势（2%）

真实问法：
- 最好的大運時間是哪一個？
- 大约那段时间，运程最好？
- 命主人生中的兩次重大事件？
- 命主何年移民到香港定居？

盘上依据：大运喜忌 + 流年与命局的作用（合冲刑害）、用神到位或受制。

答案形态：最佳/最差大运 + 具体年份 + 一句为什么。

插件现状：`trend.js` 打分表齐全，但旺衰改三要素后，临界盘会主动不排序——这是诚实，但也意味着**要给出「最好大运」必须能说清边界**。

### 10. 外貌（2%）

真实问法：
- 命主對自己儀表的要求，哪個是對？
- 體型特徵辨識：依據命盤干支組合與宮位星曜特質，推斷命主長相與體型特徵
- 命主的身材外貌如何？

盘上依据：日主五行（木长、火明、土厚、金方、水柔）、五行偏旺、食伤（秀气）、紫微命宫主星。

答案形态：体型 + 面相倾向，两三句。

插件现状：无专门出口。

### 11. 灾劫（1%）

真实问法：
- 命主男朋友被人謀殺在何年？
- 有凶劫之灾出现的时间？
- 命主在 2001 年发生了什麼事？

盘上依据：冲克日支/年支、七杀攻身、羊刃逢冲、岁运并临、三刑齐全。

答案形态：类型 + 年份 + 程度。

**注意**：这类绝不能写成断语式断言（「你某年会有血光之灾」），只能写成风险提示。

插件现状：神煞齐全，无专门出口，**也建议保持不主动输出**。

### 12. 官非（1%）

真实问法：
- 命主在哪一年鬧上官非並被警察扣留？
- 命主是因為什麼事而鬧上官非？
- 有官非刑事出现的时间吗？

盘上依据：伤官见官、官杀混杂、七杀无制、羊刃逢冲、流年冲官星。

答案形态：性质 + 年份。

插件现状：无专门出口。同上，只作提示不作断言。

## 从这张地图得出的三条设计判断

**一、答案必须带时间。** 十二类里有八类，老练师傅的回答都以「哪一年」收尾。我们的结果卡现在给的是「吉/平/忌」的分数，用户读完还是不知道自己哪年该动。

**二、先定类型，再定年份。** 事业问「做什么」，婚姻问「什么样的人」，财运问「什么量级」——这三问都是分类问题，分类错了，年份算得再准也没用。现在的解读层是「把盘面全部铺开」，缺一个先收窄到类型、再落到年份的两段式。

**三、五条以内。** 性格那类题，人类师傅给的就是三五条。我们的 `interpret.js` 有 140KB，一铺开就是几十行，用户看不完。这张地图的每一类，都该有一个「只输出三到五句」的出口。

### 为什么不做的三类

**外貌**：题库里那 8 条问的是「这个人高瘦还是矮壮」，而盘面只给五行与配偶星，五行到体型这条链每一环都不唯一——同一张盘，木旺可以说高瘦，也可以说骨架大。答了就是猜，猜错了比不答更伤信任。

**灾劫与官非**：这两类是唯一会让读者真的去改行为的输出——「明年有血光」会让人不敢开车，「后年有官非」会让人不敢签字。而它们的判据（冲、刑、羊刃、亡神）在十二类里准确率最低。所以我们把它留在「你自己看得到的神煞栏里」，不主动生成断语；用户问起，给的也是「哪一年容易累、容易起争端」，不是「会出什么事」。

这三类不做，是产品判断不是能力缺口——与其多三类让人焦虑的内容，不如把前九类的时间与量级说准。
