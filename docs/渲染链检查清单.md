# 两套渲染链检查清单

本插件有两条独立的界面：

| | 单页 | 面板 |
|---|---|---|
| 入口 | `命理排盘.html` + `src/web-ui.js` | `src/app.js`（React） |
| 结果怎么出来 | 拼 HTML 字符串塞 `#out.innerHTML` | `h()` 建 React 树 |
| 共用部分 | `src/panel-kit.js`（`window.__PP`）的 `*HTML()` 系列 | 同左 |

共用的是**卡片本身**，不共用的是**容器**：布局顺序、参数区、锁定、折叠、切换 tab 后的清理、深链落地、复制按钮，全是两条各写一遍的。所以 panel-kit 里的字段渲染改动两边自动生效，容器层的洞必须两边各查一次——0.82.0 单页巡检挖出的三个 bug（农历裸 return 卡死、起名报数缺项没拦、梅花空数默成坤）全是这一层，面板侧当时没有同等强度地查过。

## 差异点

- **锁定参数区**：单页 `src/web-ui.js:728 syncInputLock()` 扫 `.bar`；面板 `src/app.js:1106` 的 useEffect 扫 `.mp-panel`。同一套思路（不改 value，只 readOnly/disabled），但放过的节点不同。
- **问事层**：单页 `#for-ask` 里是 `#question` + `#direction` + `#tcount`；面板是 `.mp-askblock`（所问之事）+ `.mp-askonly`（询问方向）+ 牌阵 select。两者都属于「改它只重绘解读」，但牌阵决定抽几张牌，是排盘参数。
- **改方向/改问题后重算**：单页 `el('direction').addEventListener('change', …)` 重绘；面板 `refreshInterpret()`（`src/app.js:1837`）重出 `it` 并按方向重建 `trace`，不重新起局。
- **缺项拦截**：单页在 `refreshFlow()` 里算 `missing`；面板在 `go()` 里逐个 `setError()`（`src/app.js:1267` 报数 / `1315` 起名 / `1333` 农历 / `1367` 问事 / `1381`+`1389` 梅花数字）。
- **深链**：单页 `readDeepLink()`（`src/web-ui.js:928`）；面板 `src/app.js:2358` 附近。链接格式只认 `#mp=<句柄>&q=<问题>`，句柄是 `askLink()` 生成的 `mc1.<base64>.<crc>`。
- **复制提问包**：单页 `#askq` 追问框走 `Engine.askPrompt`；面板 `copyAskPrompt()`（`src/app.js:1872`）走 `Engine.buildEventPrompt`。两个函数不是同一个。

## 这轮查出来的（都在 0.82.0 之后、未发版）

1. **单页问事类永远出不了盘**（`src/web-ui.js`）：`#question` 只绑 `change`，回调又只在已出结果时才动，从不 `refreshFlow()`。填完问题按钮还是灰的、提示还写「还差：所问之事」。塔罗 / 六爻 / 梅花 / 奇门全线卡在第一步。修法：补 `input` 监听，仅在非 LOCKED/CALC 态调 `refreshFlow()`。
2. **单页梅花数字起卦同病**：字段监听列表漏了 `upper` / `lower`，两个数填了也没反应。
3. **「询问方向」被当成排盘参数锁死**（两条链都有）：它只改解读层，锁住等于出盘后永远切不了。单页在 `syncInputLock()` 里放行 `#question` / `#direction`；面板放行 `.mp-askbox` / `.mp-askblock` / `.mp-askonly`。
4. **面板「所问之事」被锁**（`src/app.js`）：放过列表只有 `.mp-askbox`（追问框），`.mp-askblock`（所问之事）没放，出盘后 `readOnly`，`onBlur → refreshInterpret` 成了永远触发不了的死代码。
5. **e2e-dom 深链用例写错了链接格式**：手写 `#mp=<encodeURIComponent(JSON)>`，而解析器认的是带校验位的句柄。那条链接从来没生效过，测试只看 `out` 长度够不够，就一直跟着烂。现在改成用 `Engine.askLink()` 现生成，并加断言「落到对应体系」「还原提示写明这张盘与问题」。

## 还没做的

- 面板侧的 9、10、15（生时校正候选、换盘残留、深色主题）没同等强度测过。
- 单页面板的锁定态各写一遍扫描逻辑，早晚还会漂。真要合并，得把「哪些控件属于问事层」挪成 `panel-kit` 里的一个标记类（面板已经是 `.mp-askonly` 这个思路），单页跟着用同一个类名，别再各写一份 `id` 白名单。
