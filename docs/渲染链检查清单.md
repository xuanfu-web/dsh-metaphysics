# 两套渲染链检查清单

本插件有两条独立的界面：

| | 单页 | 面板 |
|---|---|---|
| 入口 | `命理排盘.html` + `src/web-ui.js` | `src/app.js`（React） |
| 结果怎么出来 | 拼 HTML 字符串塞 `#out.innerHTML` | `h()` 建 React 树 |
| 共用部分 | `src/panel-kit.js`（`window.__PP`）的 `*HTML()` 系列 | 同左 |

共用的是**卡片本身**，不共用的是**容器**：布局顺序、参数区、锁定、折叠、切换 tab 后的清理、深链落地、复制按钮，全是两条各写一遍的。所以 panel-kit 里的字段渲染改动两边自动生效，容器层的洞必须两边各查一次——0.82.0 单页巡检挖出的三个 bug（农历裸 return 卡死、起名报数缺项没拦、梅花空数默成坤）全是这一层，面板侧当时没有同等强度地查过。

## 差异点

- **锁定参数区**：两条链都调 `src/panel-kit.js` 的 `pp.lockParams(root, locked)`，名单只有一份（`pp.ASK_FREE`）。单页传 `.bar`（`src/web-ui.js:728 syncInputLock()`），面板传 `.mp-panel`（`src/app.js:1100` 的 useEffect）。问事层靠 `mp-askfree` 标记类认，单页的 `#question` / `#direction` 已在 `tools/build-html.mjs` 模板里挂上，面板的 `.mp-askbox` / `.mp-askblock` / `.mp-askonly` 也列在同一份名单里。
- **问事层**：单页 `#for-ask` 里是 `#question` + `#direction` + `#tcount`；面板是 `.mp-askblock`（所问之事）+ `.mp-askonly`（询问方向）+ 牌阵 select。前三者都属于「改它只重绘解读」，但牌阵决定抽几张牌，是排盘参数，不在放过名单里。
- **改方向/改问题后重算**：单页 `el('direction').addEventListener('change', …)` 重绘；面板 `refreshInterpret()`（`src/app.js:1837`）重出 `it` 并按方向重建 `trace`，不重新起局。
- **缺项拦截**：单页在 `refreshFlow()` 里算 `missing`；面板在 `go()` 里逐个 `setError()`（`src/app.js:1267` 报数 / `1315` 起名 / `1333` 农历 / `1367` 问事 / `1381`+`1389` 梅花数字）。
- **深链**：单页 `readDeepLink()`（`src/web-ui.js:928`）；面板 `src/app.js:2358` 附近。链接格式只认 `#mp=<句柄>&q=<问题>`，句柄是 `askLink()` 生成的 `mc1.<base64>.<crc>`。
- **复制提问包**：单页 `#askq` 追问框走 `Engine.askPrompt`；面板 `copyAskPrompt()`（`src/app.js:1872`）走 `Engine.buildEventPrompt`。两个函数不是同一个。

## 这轮查出来的（都在 0.82.0 之后、未发版）

1. **单页问事类永远出不了盘**（`src/web-ui.js`）：`#question` 只绑 `change`，回调又只在已出结果时才动，从不 `refreshFlow()`。填完问题按钮还是灰的、提示还写「还差：所问之事」。塔罗 / 六爻 / 梅花 / 奇门全线卡在第一步。修法：补 `input` 监听，仅在非 LOCKED/CALC 态调 `refreshFlow()`。
2. **单页梅花数字起卦同病**：字段监听列表漏了 `upper` / `lower`，两个数填了也没反应。
3. **「询问方向」被当成排盘参数锁死**（两条链都有）：它只改解读层，锁住等于出盘后永远切不了。单页在 `syncInputLock()` 里放行 `#question` / `#direction`；面板放行 `.mp-askbox` / `.mp-askblock` / `.mp-askonly`。
4. **面板「所问之事」被锁**（`src/app.js`）：放过列表只有 `.mp-askbox`（追问框），`.mp-askblock`（所问之事）没放，出盘后 `readOnly`，`onBlur → refreshInterpret` 成了永远触发不了的死代码。
5. **e2e-dom 深链用例写错了链接格式**：手写 `#mp=<encodeURIComponent(JSON)>`，而解析器认的是带校验位的句柄。那条链接从来没生效过，测试只看 `out` 长度够不够，就一直跟着烂。现在改成用 `Engine.askLink()` 现生成，并加断言「落到对应体系」「还原提示写明这张盘与问题」。
6. **深色下共用层 `.ask-sep` 分隔符看不见**（合清单复查新挖）：`src/panel-kit.js:658` 原来用 `var(--dimline)`，深色下 `#5f5849` 压在 `--band` `#26261f` 上只有 2.16:1，夹在「问题」和「询问方向」中间的竖线淡到读不出。单页的深色测试页没排带问题的盘，所以一直没露；面板打开即出盘才撞上。修法：改用 `var(--muted)`。这是共用卡片层，两条链一起生效。顺带把面板深色检查从「只验选中卡片」补成全页扫（与 `e2e-dom.mjs:352-400` 同强度），这才把它照出来。

## 合清单复查（2026-11-17）

面板侧 9、10、15 三项按单页同等强度补齐，都过：

- 9 / 10 在 `tools/e2e-panel.mjs` 六·五：出八字盘 → 点「计算候选时辰」→ 换日期重排后候选清空 → 只改出生地不重排，再点一次候选与之前逐字相同（验 `runRectify` 取 `result.at` / `result.address`，不读表单此刻值）。单页对应 `e2e-dom.mjs:252-290`。
- 15 在 `tools/e2e-panel.mjs` 八：沿 `e2e-dom` 的对比度算法，扫 `#main` 里所有「自己直接含文字」的元素，字色/底色比值 < 2.2 即报，渐变底取各色均值。补测前没有这一层，所以 `.ask-sep` 藏了这么久。
- 数字：`node tools/e2e-panel.mjs` 163 → **168 通过 0 失败**；`node tools/e2e-dom.mjs` 161 项通过；`node tools/build-all.mjs --gate` 207/207、11483 断言；`client.js` gzip 121KB，未撞 128KB 上限。

第 11 项旧记「面板只测了 `fillDeepForm` 一侧」已过时：`e2e-panel.mjs:616-679` 有完整深链落地用例（真句柄、切 tab、问题落地、无报错），一并刷成 ✅。

## 第二轮复查：第 12、16 项 + 锁定逻辑合并（2026-11-17）

- **16 面板侧**（`tools/e2e-panel.mjs` 六·六）：八字排盘后断言 `mp-bzcg` + 「袁天罡称骨」、`mp-mar`、`mp-life` 且 `data-face` 正好 6 个、首屏 `[aria-label="一眼看"]` 有字。这一项比单页那条更要紧：称骨不在 chart 分块里，面板靠 `go()` 里 `ensureEngine('chenggu')` 按需拉一次，拉不到会被 `catch` 吞成 `null` —— 既不报错也不出卡，正是 0.76 栽过的坑。测试里先 `waitForFunction` 等 `mp-bzcg` 出现再判断，不拿「刚排完那一刻」当结论。
- **12 面板侧**：补上单页那把尺 `length > 2000`（实测 3693 字），此前只验了三段关键串在不在。
- **锁定扫描逻辑合并**：`src/panel-kit.js` 新增 `pp.ASK_FREE` 与 `pp.lockParams(root, locked)`，名单一份、规则一份、`mp-askfree` 标记类作为契约。单页 `syncInputLock()`、面板 useEffect 都改成调它，各自只剩「传哪个根节点 + 切自己的 class」。共用层没就绪时单页保守全锁，不赌哪几个控件是问事层。
- **顺带把断言改成守契约而不是守字面串**：`test/ask.test.mjs` 三条正则原来写死 `<textarea id="question" rows="2"`，加个 class 就断——改成 `[^>]*` 且要求带 `mp-askfree`（90→93）；`test/panel-cache.test.mjs` 第三节原来在面板源码里数 `n.closest('.mp-askbox…')`，逻辑搬走后改成守「面板确实交出去、不再自己扫」+「共用层名单含三类」（24→31）。
- **数字**：`node tools/e2e-panel.mjs` 168 → **176 通过 0 失败**；`node tools/e2e-dom.mjs` 161 → **165 项通过**；`node tools/build-all.mjs --gate` 207/207、**11486 条断言**；`client.js` gzip **124417**（上限 128000，余量 3583）。
