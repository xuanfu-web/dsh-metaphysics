# 问事解读提示：怎么把一张盘讲成他能用的话

> 适用体系：六爻、梅花易数、大六壬、奇门遁甲、塔罗、小六壬。
> 命盘类（八字、紫微）不在此列——它们回答的是「这个人是什么结构」，不是「这件事成不成」。

## 为什么要有这套东西

问事体系的盘面符号极多。模型（和不少人）拿到一屏数据后，最省力的写法是：

> 「世爻旺相，用神得生，吉。」

这不是解读，是把符号念了一遍，对你没有任何用。**真正的问题不是准不准，而是这句话回答不了你问的那件事。**

所以这里把流程固定下来，一句话概括：

> **先确认问什么事 → 找到对应符号 → 看它落在哪、与谁什么关系 → 回到现实核对。**

四步之外，还加了两条：开口前先自检三问，以及所有结论必须能回到现实。

---

## 第一步：先处理「时辰未知」

问事体系全靠**起课那一刻**定盘。差一个时辰，日辰、旬空、月建全换，盘就不是这张盘了。

所以时间不明时**不排盘**，先问清三件事：

1. 是按现在这一刻起，还是按你打算行动的那一刻起？
2. 钟表时间还是农历？
3. 在哪个城市？（真太阳时会差几分钟到十几分钟）

同时把问题压成一句话：**主语 + 时间 + 可验证的结果**。

- 好：「下周三之前，这份工作的书面 offer 能不能拿到」
- 差：「我最近运势怎么样」

写不出这个句式，说明问题还没成形。这时候看盘只会放大焦虑。

---

## 第二步：先分清问的是哪一类事

解读前必须先落到下面五类之一，笼统问「运势」不属于任何一类，要请他重说。

| 类型 | 典型问法 |
|---|---|
| 工作 / 事业 | 这份工作要不要接、这次面试能不能过 |
| 感情 / 关系 | 他还会不会联系我、这段关系要不要继续 |
| 生意 / 合作 | 这笔合作值不值得谈、这个项目能不能落地 |
| 某件事能不能推进 | 这次沟通能否推进、这个申请能不能批 |
| 挑日子 / 看时机 | 哪天办这件事顺、这周去谈行不行 |

---

## 第三步：每个体系谁代表「我」、谁代表「事」

**这一层不能互相借。** 六爻的世应拿到梅花里毫无意义，塔罗的牌位也不能塞进六壬。各体系自己的取法如下：

### 六爻（纳甲）

- **我 = 世爻**；**对方 / 事 = 应爻**
- 用神按六亲取：
  - 工作、职位、上级 → **官鬼**
  - 钱财、合作分利 → **妻财**（同看兄弟，兄弟动主分我之财）
  - 感情 → 男看**妻财**、女看**官鬼**，再看世应是否相生相合
  - 文书、消息、答复 → **父母**
- **用神两现时必须说明「未定」**：先看持世、临日月、发动者，挑不出来就直说挑不出来。

### 梅花易数

- **我 = 体卦**（不动的那一卦）；**事 = 用卦**（动爻所在）
- 只看生克方向。体用标注「大吉」也只是条件好，不是结果已经发生。

### 大六壬

- **我 = 日干**；**对方 / 事 = 日支**
- **三传看过程**：初传起因、中传中途、末传收尾——末传比初传更接近结果。

### 奇门遁甲

- **我 = 日干（天盘）落宫**；**事 = 时干落宫**
- 门代表「这件事是什么形态」：开门启动公开、生门生长收益、休门休息等待、伤门损耗冲突、杜门阻碍隐藏、景门信息曝光、死门停止收尾、惊门变动突发。
- **门名不是吉凶判决**，要看它和日干宫、时干宫的关系，以及有没有空亡、门迫、入墓。
- 中宫无门无神，按寄宫（多寄坤二）取，且要说清「这是寄宫」。

### 塔罗

- **牌位决定它代表什么**（过去 / 现在 / 未来，或问题 / 阻碍 / 建议），牌面只说明它是什么样子。
- 「死神」在这一位可能只是「该结束了」，不等于完蛋。

### 小六壬

- 只有一宫落位，**它同时代表事与势**。
- 它**没有「我」的独立符号**，所以给不了「我 vs 对方」的对比——这是口径限制，别硬补一个出来。

---

## 第四步：看状态，别把符号名当结论

三件事按顺序说，缺一件都不算读完：

1. **落在哪**：这件事处在什么领域、什么处境（旺 / 衰 / 空 / 实 / 动 / 静 / 被制 / 得助）。
2. **遇什么门 / 什么关系**：门是形态，关系只有四种——
   - **生**：得助（说清谁生谁）
   - **克**：受制（说清谁克谁）
   - **合**：连接、聚合（合住也可能意味着被拴住）
   - **冲**：变动、对立、打破（冲开也可能意味着解脱）
3. **减分项**：空亡、入墓、伏藏、用神两现——要么说清它压低了什么，要么别提。**不要念一遍名字就过去。**

---

## 开口之前：先自检三问

1. 你说「我」是哪个符号？为什么是它，不是别的？
2. 机会在哪一处、阻碍在哪一处、对方态度在哪一处？各自依据哪条关系？
3. 盘上有没有相反提示？你为什么采信这一边？

**三问答不全，就还没到能下结论的程度**——先把答不出的那条写出来。

---

## 最后：必须回到现实核对

盘面只给方向，给不了证据。按类型给他「明天可以去查、去问、去要」的东西：

| 类型 | 核对什么 |
|---|---|
| 工作 | 书面邀约、岗位职责、薪酬范围、试用期；最坏情况的损失 |
| 感情 | 对方的具体行动、持续投入的时长、有无第三方、你的底线 |
| 合作 | 资源能否落到具体人 / 钱 / 渠道、合同条款、执行人、退出机制 |
| 推进某件事 | 截止日期是谁定的、实际成本、可逆性、成功的样子 |
| 挑日子 | 必须到场的人、硬约束、备选日期 |

**口头承诺不算核对**，这是这套方法里最硬的一条。

---

## 禁止清单

- 只使用盘面上出现的符号；没给的不许自己补。
- 不许「旺相所以好」「死神所以完蛋」这种一句话断语。
- 不给医疗、法律、投资的具体结论。
- **不给公历日期**——应期只谈「什么条件下会出现信号」。
- 不确定就写不确定，并说明缺哪条信息才能确定。

## 怎么用

### 命令行（直接拿到可粘贴的提示）

```bash
# 六爻，问工作，指定摇出的六爻
node tools/event-prompt.mjs --system liuyao --kind career \
  --question "下周三前能不能拿到书面 offer" --lines 9,7,8,8,7,6 --gender male

# 奇门，问合作
node tools/event-prompt.mjs --system qimen --kind business --question "这笔合作值不值得谈"

# 时间没定：只输出「先问时间」，不排盘
node tools/event-prompt.mjs --system liuyao --no-time
```

参数：`--system liuyao|meihua|daliuren|qimen|tarot|xiaoliuren`、`--kind career|love|business|action|day|other`、`--datetime`（默认当前）、`--lines`、`--gender`、`--count`（塔罗张数）。

输出是一段完整的提示：把盘面事实填好、用神与理由列好、三追问与现实核对都带上，直接交给模型即可。

### 代码里

```js
import { buildEventPrompt } from './engine/event-prompt.js';

const p = buildEventPrompt(computeResult, {
  question: '下周三前能不能拿到书面 offer',
  kind: 'career',
  gender: 'male',
  timeKnown: true,       // 传 false 会返回「先问时间」的拦截文本，不排盘
});
if (!p.blocked) console.log(p.text);
```

奇门另有 `engine/qimen-prompt.js`（门 / 星 / 神 / 干 的取用神更细），`buildEventPrompt` 会自动委派过去，两套提示不会各说一套。

## 与「能力边界」的关系

这套提示不承诺准确。它只保证三件事：

1. 每个符号都能说出**为什么取它**；
2. 每个判断都能指到**盘上哪一处**；
3. 每个结论都能落回**现实里可核对的东西**。

至于盘面这套对应关系在现实里成不成立——**未经检验**，插件任何地方都不保证。这话写在 `engine/limits.js` 里，也在每份报告的最末。
