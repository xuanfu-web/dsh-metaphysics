### 这批改了什么

选中块的字色不再写死白色。深色主题下 `--dsw-alias-brand-primary` 本身常是浅色，白字压上去对比度跌到 1.x，等于没有字。

- `src/core.js`：新增 `pickOnColor` / `contrastRatio` / `luminance` / `parseRGB` / `hexToRGB`，按 WCAG 对比度在两候选中择优
- `src/app.js`：运行时量一次真实品牌色，写进 `--mp-on-brand`；监听系统偏好与 `html` 的 `class` / `data-theme` 变化重算；量不到时 CSS 仍以 `#fff` 兜底，不会比原来更差
- 所有「品牌色底 + `#fff` 字」的选中态（页签、工具条、分段、选项、主按钮、chip）统一改读该变量
- 补 `test/core.test.mjs` 对比度用例、`test/theme.test.mjs` 回归

### 顺带记两条

- **构建顺序不能反**：`check-assertions.mjs --update` → `build-client.mjs` → `build-html.mjs`。反了会把旧断言数嵌进单页。
- `test:ci` 自己会再跑一次 `build-client`，本次已复核重跑后产物零漂移（`git status` 干净），所以「先 HTML 后 CI」不会让 HTML 里的断言数过期。
