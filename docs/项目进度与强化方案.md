- 测试：`cmd /c "npm run test:ci"`（PowerShell 直接跑 `npm` 会撞执行策略）
- 发布：`NPM_CLI=<node>\node_modules\npm\bin\npm-cli.js`，`NPM_TOKEN` 来自
  `~/.dsh/metaphysics-autopublish.json`（含 npmToken / githubToken，ACL 仅当前用户，不入库）
- 推送：`git -c credential.helper= -c http.https://github.com/.extraheader="Authorization: Basic <b64>" push origin main`

  也可以手写 `.git/HEAD`（`ref: refs/heads/main`）与 `.git/config` 后 `git reset`
- registry CDN 有边缘缓存：新版本查不到时加 `?cb=<随机>`；等几分钟自然过期
- GitHub 连接间歇失败：重试即可；自动发布的 push 失败会终止本轮（下一轮重试）
- 自动发布：任务 `DSHMetaphysicsAutopublish`（每天 12:00）；配置 `~/.dsh/metaphysics-autopublish.json`；
  状态 `.autopublish-state.json`、日志 `tools/.autopublish.log`（三者 gitignore）
- 版本约定：一个可感知改动一个版本；未发布的中间版本在发下一版时标「已并入 x.y.z」
